# 2048 Game in C

C 언어로 만든 **터미널 2048 게임**입니다.
4×4 판에서 같은 숫자 타일을 밀어서 합치고, 2048을 만드는 것이 목표입니다.
회원가입과 로그인, 점수 기록, 랭킹 기능을 함께 구현합니다.

> 2048은 2014년 Gabriele Cirulli가 만든 숫자 퍼즐 게임입니다.
> 이 저장소는 그 규칙을 C로 직접 구현해 보는 학습용 프로젝트입니다.

---

## 주요 기능

- **2048 게임**
  - `w` `a` `s` `d`로 상하좌우 이동, `q`로 종료
  - 같은 숫자가 부딪히면 합쳐지고, 합쳐진 값만큼 점수 증가
  - 판이 실제로 움직였을 때만 새 타일 생성 (2: 90%, 4: 10%)
  - 2048을 만든 뒤에도 계속 플레이 가능
  - 빈칸도, 합칠 수 있는 이웃도 없으면 게임 오버
- **회원가입 / 로그인**: 아이디와 비밀번호를 파일에 저장
- **기록 저장**: 게임이 끝나면 아이디, 점수, 최대 타일을 파일에 추가
- **랭킹**: 전체 기록을 점수 순으로 정렬해 TOP 10 출력, 내 기록 보기

## 실행 방법

```bash
gcc -Wall -o 2048 2048.c
./2048
```

표준 C 라이브러리만 사용하므로 macOS, Linux, Windows(MinGW) 어디서든 같은 코드로 컴파일됩니다.

## 프로그램 흐름

```
[시작 메뉴]  1. 로그인   2. 회원가입   3. 랭킹 보기   0. 종료
                │
          로그인 성공
                │
[게임 메뉴]  1. 게임 시작   2. 랭킹 보기   3. 내 기록   0. 로그아웃
                │
          게임 루프 → 게임 오버 또는 q → 기록 저장
```

## 왜 2048인가

| 이유 | 설명 |
|---|---|
| 턴제 구조 | 키 한 번에 한 번 이동하므로 실시간 처리 없이 표준 입력만으로 동작 |
| 2차원 배열 | 4×4 배열과 반복문만으로 게임 로직이 완성되어 분석하기 좋음 |
| 확장 가능성 | 회원, 기록, 랭킹에 구조체, 파일 입출력, 동적 할당을 직접 적용 가능 |
| 익숙한 규칙 | 이미 해 본 게임이라 코드와 실제 동작을 바로 비교하며 이해 가능 |

## 이 프로젝트에서 다루는 것

1. **2차원 배열과 인덱스 조작**: `(i, j)` ↔ `i * SIZE + j` 변환
2. **회전으로 함수 하나를 재사용하는 설계**: "한 줄을 왼쪽으로 밀기"만 구현하고, 나머지 방향은 판을 회전시켜 처리
3. **구조체**: 회원 정보(`User`)와 게임 기록(`Record`)을 하나로 묶어 관리
4. **파일 입출력과 동적 할당**: 기록 파일을 읽어 개수만큼 `malloc`으로 배열을 만들고 정렬
5. **이식성**: `conio.h` 같은 특정 OS 전용 기능 없이 동작

## 핵심 알고리즘: 한 줄 밀기

```
[2, 0, 2, 4]
  ① 당기기      → [2, 2, 4, 0]   0을 빼고 왼쪽으로 붙이기
  ② 합치기      → [4, 0, 4, 0]   옆과 같으면 합치기 (한 번 합쳐진 타일은 다시 합치지 않음)
  ③ 다시 당기기 → [4, 4, 0, 0]   합치면서 생긴 빈칸 메우기
```

| 이동 | 처리 |
|---|---|
| 왼쪽 | 밀기 |
| 아래 | 시계 방향 1회 회전 → 밀기 → 3회 회전 |
| 오른쪽 | 2회 회전 → 밀기 → 2회 회전 |
| 위 | 3회 회전 → 밀기 → 1회 회전 |
